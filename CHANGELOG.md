## 1.0.0 - 2026-09-27

Initial stable release of Sillar Toast.

- React provider, viewport, card, and hooks.
- Framework-neutral toast store and API.
- Success, info, warning, danger, loading, and default variants.
- Promise-aware notifications.
- Dismissible and actionable toast records.
- Accessible `status` and `alert` live-region semantics.
- Keyboard hotkey support for focusing the notification region.
- Auto-dismiss progress indicator with hover/focus pause.
- Light and dark CSS variable themes.
- Focus styling, reduced-motion support, and no Radix/UI runtime dependency.
